# sparkdock

Spark list/dock set operations for shell-friendly data wrangling.

**Site:** https://theworker02.github.io/sparkdock/

## Install / run

```bash
git clone https://github.com/theworker02/sparkdock.git
cd sparkdock
node src/cli.js
node --test
```
